  # Sistema de Configurações com o Topbar

> **Configurações completas, fáceis de aprender e entender também**, por conta dos comentários dentro do `SettingsUI`.

O sistema foi desenvolvido pensando em ser **bem universal**, oferecendo boa compatibilidade e organização.

Falando em compatibilidade, **todos os dispositivos possuem suporte nativo**, ou seja, não é necessário utilizar "gambiarras" para adaptar o sistema entre diferentes dispositivos.

### 🕹️ Métodos de entrada

Além dos dispositivos, o sistema considera diferentes métodos de interação:

* ⌨️ **Teclado**
* 🖱️ **Mouse**
* 👆 **Touch / Tela sensível ao toque**
* 🎮 **Controle / Gamepad**
* 🥽 **VR / Realidade Virtual**

> **Observação:** a disponibilidade de determinados recursos pode variar de acordo com a plataforma, dispositivo e recursos atualmente oferecidos pelo Roblox.

## Atenção à compatibilidade

**NÃO UTILIZA o Topbar do HD.**

Ou seja, não utiliza, por exemplo:

* 3.v
* Plus
* Nenhuma versão dessas

Em vez disso, o sistema utiliza **seu próprio Topbar**, não necessitando de dependências de terceiros.
